# New Haven regional example

`regional-builder.sav` is a fork version 363 save generated by `tools/renaissance/verify_regional.py` from `regional-flat.png`, seed 20261101. It contains the two-year native vehicle simulation: a farm, food processor, shops, six housing lots, power, water, public services, three freight stops, a depot and four trucks. No freight was injected into the example.

Use the regional executable and static Renaissance Meadow base presentation. The previous fork and upstream cannot load this new save. The old coastal example remains separately available and unmodified.

Open `Launch-TransportRenaissance.cmd`, select Load Game → regional-builder.sav, then use the Towns toolbar's Regional development panel. New worlds keep the feature disabled unless the player opts in through Settings before world creation. See `docs/renaissance/regional-development.md` for controls, costs and limits. The normal build/package scripts include this example. Regenerate it with `verify_regional.py` and copy the verified output from `artifacts/regional-verification/run-0/save/` here when intentionally updating the fixture.
